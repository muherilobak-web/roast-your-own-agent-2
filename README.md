A single self-deprecating roast line about Doc, our own AI agent — the one who
answers a simple question with twelve questions of his own, until the user has
done all the work and still thanks him for helping. One line, written to
`/output/entry.txt` by a dependency-free Node program.

## Run it

```sh
npm start
# or
node main.ts
```

This writes the roast line to `/output/entry.txt` (no trailing newline).
